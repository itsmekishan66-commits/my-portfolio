# Kishan Shah — Portfolio

Minimal animated portfolio built with **Next.js**, **Framer Motion**, and **21st.dev-style** UI patterns (shadcn-inspired components).

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit `src/lib/data.ts` to update:

- Email & social links
- Skills and proficiency
- Work experience
- Project cards

## Deploy

```bash
npm run build
```

Deploy to [Vercel](https://vercel.com) or any Node host.
